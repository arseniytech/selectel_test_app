# Selectel Test Application

A modern Angular 19 application built for a technical assessment. This project demonstrates proficiency with Angular, TypeScript, and modern web development practices.

## 🎯 Project Overview

This is a test assignment for Selectel showcasing:
- Modern Angular 19 framework capabilities
- TypeScript best practices
- Responsive UI design
- Clean component architecture

## 🛠 Tech Stack

- **Framework:** Angular 19
- **Language:** TypeScript
- **Build Tool:** Angular CLI
- **Styling:** CSS/SCSS
- **State Management:** Angular Services / RxJS

## 🚀 Quick Start

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation & Running

```bash
# Install dependencies
npm install

# Start development server
npm start

# Application runs at http://localhost:4200
```

### Build for Production

```bash
npm run build
# Output will be in dist/ directory
```
